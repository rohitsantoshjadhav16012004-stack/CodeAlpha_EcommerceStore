# CodeAlpha E-Commerce Store

A full-stack e-commerce web application developed as part of the CodeAlpha Full Stack Development Internship.

## 📌 Project Overview

CodeAlpha Store is a simple and professional e-commerce website where users can browse products, view product details, create an account, log in, add products to a shopping cart, and place orders.

The project includes both frontend and backend functionality with MongoDB database integration.

## ✨ Features

- 🛍️ Product catalogue
- 🔎 Product details page
- 🛒 Shopping cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Clear shopping cart
- 🔢 Cart item counter
- 👤 User registration
- 🔐 User login
- 🔒 Password hashing using bcrypt
- 📦 Checkout page
- 🏠 Delivery address collection
- 🧾 Order processing
- 💾 MongoDB database storage
- 📱 Responsive design
